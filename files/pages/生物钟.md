# 生物钟情况

一个大致的日常作息参考，方便知道我通常在什么时段清醒、专注或正在休息。

## 日常时段（UTC+8）

| 时间段 | 状态 | 通常在做什么 |
| --- | --- | --- |
| `00:00 - 07:30` | 睡眠休息 | 离线充电中 |
| `07:30 - 09:00` | 早间唤醒 | 醒来、洗漱、吃早饭 |
| `09:00 - 12:00` | 上午专注 | 写代码、学习、处理正事 |
| `12:00 - 14:00` | 午间小憩 | 午饭与简短休息 |
| `14:00 - 18:30` | 下午创作 | 做项目、写文章、折腾新东西 |
| `18:30 - 23:30` | 夜间自由 | 听音乐、散步、看片或摸鱼 |
| `23:30 - 24:00` | 准备睡觉 | 远离屏幕，准备入睡 |

首页顶部的生物钟 Bar 会根据你当前时间自动计算并标出所处时段；如果想改时间划分，直接编辑 `site.json` 里的 `clock.slots` 即可。

不过话说回来，我的生物钟实际上是很灵活多变的，我的意思是。
只要我想要，我可以彻夜不睡，也可以规律作息
唯一比较困难的就是一直规律作息，我可不是那么死板的人对吧
